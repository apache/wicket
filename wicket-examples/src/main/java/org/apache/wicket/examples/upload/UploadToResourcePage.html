Wicket can upload to a mounted resource.

This upload is done with a plain XMLHttpRequest and does not block Wicket AJAX

Files chosen several times or dropped on the zone add up in a list, from which each can be removed before the upload

The limits of the field, 100 KB in all, 90 KB a file and 5 files, are checked before anything is sent: files beyond them are refused without being uploaded

Upload progressbar has been updated to work with this component
