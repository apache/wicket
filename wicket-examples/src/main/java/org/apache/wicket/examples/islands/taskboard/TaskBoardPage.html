A team board. The board is a React component, mounted as a Wicket island; the summary next to it is plain Wicket. Drag a card to another column: the board moves it at once and asks the server, which may refuse. Double-click a card to edit it.

This example was built without its JavaScript. Build the examples with -Pjs-test, or run a Vite dev server, to use it.

How this page is built

The board is not kept in the page: it lives in an application-wide repository, and the page loads it for every request. Each session gets a board of its own, so two tabs of one browser share it as two users would. The source viewer shows the Java classes and the React modules under frontend/src/taskboard.

  • Moving a card (TaskBoard) is optimistic: React shows the move at once and calls move. The server checks the column's limit and the board's version. When it accepts, the response updates the board island and the summary. When it refuses, the card goes back; a refusal because the board changed also brings the current board, as "Let a teammate move a card" shows.
  • Double-clicking a card calls open, which opens a plain Wicket ModalDialog. Its form mixes classic fields with two form islands: a rich-text editor (RichTextField) and a date picker (DueDateField). Both take part in validation and feedback like any form component.
  • The description is HTML from the browser, so it is untrusted: RichTextField runs it through an allowlist sanitizer before it reaches the card. The preview renders it unescaped only because of that.
  • The filter writes a client store that the board reads, so filtering never reaches the server. The assignee suggestions and the chart come from the page-less endpoints members and throughput, which run without the page lock. The page gives them a handle for the board instead of its id, so the browser cannot ask about another board; the endpoints still check that the session may see it. A move invalidates throughput, and the chart fetches it again.

To change the React components with hot reload, run npm run dev in wicket-examples/src/main/frontend and start the examples in development mode with -Dwicket.islands.devServer=http://localhost:5173.
