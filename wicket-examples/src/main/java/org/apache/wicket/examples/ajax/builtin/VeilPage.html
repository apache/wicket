Page veil

Page clicks:

  • Slow request: takes a second, so the spinner shows.
  • Medium request: takes 400 ms, so the spinner shows, and stays for its minimum time of 500 ms.
  • Fast request: takes 100 ms, the page is veiled but no spinner shows.
  • Unveiled request: takes a second, but opts out of the veil, so the page stays usable.

Nested local veils

This panel has its own veil with the default timings: the spinner shows after 300 ms and stays for at least 500 ms. Requests fired from inside it veil only the panel, so the rest of the page stays usable.

Outer panel clicks:

Slow request from the outer panel: takes two seconds and veils the whole outer panel, inner panel included.

This nested panel has a veil of its own, configured with setSpinnerDelay(100 ms) and setMinimumSpinnerTime(1 s). Requests fired from inside it veil only this panel: the innermost veil takes the request.

Inner panel clicks:

  • Slow request from the inner panel: takes two seconds.
  • Short request from the inner panel: takes 200 ms, but the spinner shows after 100 ms and stays for a second.
