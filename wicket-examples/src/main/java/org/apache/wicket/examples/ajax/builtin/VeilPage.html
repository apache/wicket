Page veil

Page clicks:

  • Slow request: takes a second, so the spinner shows.
  • Medium request: takes 400 ms, so the spinner shows, and stays for its minimum time of 500 ms.
  • Fast request: takes 100 ms, the page is veiled but no spinner shows.
  • Unveiled request: takes a second, but opts out of the veil, so the page stays usable.

Nested local veils

This panel has its own veil with the default timings: the spinner shows after 300 ms and stays for at least 500 ms. Requests fired from inside it veil only the panel, so the rest of the page stays usable.

Outer panel clicks:

Delegated clicks

One AjaxEventBehavior on the list handles the clicks on all of its rows through a child selector, and every row has a local veil of its own. A click on a row takes a second and veils only the row that was clicked, not the list or the page.
